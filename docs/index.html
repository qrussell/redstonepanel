INSTALL & UPGRADE

Ubuntu 24.04, 26.04 and 26.10, Debian 13 and 64-bit Raspberry Pi OS through the GPG-signed APT repository, or Windows 11 and Windows Server 2022/2025 with the installer (preview).

Verifies the signing key, configures the qrussell-repo APT source, and installs redstonepanel.

curl -fsSL https://raw.githubusercontent.com/qrussell/redstonepanel/main/install.sh | sudo sh

Tip: Testing on an unsupported Debian/Ubuntu derivative? Prefix with FORCE=1 to bypass the OS version guard.

Keep RedstonePanel up to date alongside your regular Ubuntu security patches using standard APT commands:

sudo apt update && sudo apt upgrade

Repository URL: https://qrussell.github.io/qrussell-repo/deb

Windows 11 or Windows Server 2022/2025, 64-bit. Download RedstonePanel-<version>-x64.msi from the latest release, open it, then open http://localhost:8080 and sign in as admin with the password in first-sign-in.txt.

Download the installer Windows guide

Preview: Java servers on one computer. Bedrock, modpacks, limits and clusters come to Windows in 1.23 and 1.24. The installer isn't signed yet: in SmartScreen choose More info → Run anyway.

Every package in the APT repository is cryptographically signed. Verify the official GPG signing key fingerprint:

9994A9EB39EB3C101C949FB2012BA14E0FE3A355

Automatically verified by install.sh before adding the APT repository keyring.
