Java is installed when a server needs it, and only the versions your servers use stay installed.

## Changed

- **The package no longer installs Java.** `openjdk-25-jre-headless` moves from Recommends to Suggests, so a host that only runs Bedrock never gets Java. Upgrading doesn't remove the Java you have.

## Added

- **Install the Java a server needs, from the panel (admins).** Creating, updating or restoring a Java server whose Java isn't installed asks to install the right `openjdk-N-jre-headless` (for example Java 21 for Minecraft 1.21.4), shows apt's progress in the Console, and then carries on. Servers that were waiting for that Java, such as an imported one that couldn't start, are moved onto it.
- **Dashboard → Supporting services → Java** lists each installed Java with the servers that use it, the versions servers need, **Install** for any other version and **Remove** for one that no server uses. **Needs attention** mentions an unused Java.
- **Removing a Java** purges only its JRE package and the dependencies that only it needed. It's refused while a server uses it, or when apt would also remove something else (a JDK you installed, for example).
- **Maintenance → Java** shows which Java a server runs on and switches it to another installed Java that's new enough. A running server restarts.

Each server's systemd unit still names its own Java by full path, so servers needing Java 21 and Java 25 run side by side.

## Installing

RedstonePanel runs on **Ubuntu 24.04 and 25.04**. The easiest way to install it, and to get every later version with `apt upgrade`, is the signed **qrussell-repo** apt repository:

```bash
sudo apt install -y curl ca-certificates
curl -fsSL https://qrussell.github.io/qrussell-repo/deb/qrussell-repo.gpg | sudo tee /usr/share/keyrings/qrussell-repo.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/qrussell-repo.gpg] https://qrussell.github.io/qrussell-repo/deb ./" | sudo tee /etc/apt/sources.list.d/qrussell.list
sudo apt update
sudo apt install redstonepanel
```

Then open **http://&lt;server&gt;:8080/** and sign in with a Linux account in the `sudo` group.

To check the repository key before trusting it, `gpg --show-keys /usr/share/keyrings/qrussell-repo.gpg` should show the fingerprint `9994A9EB39EB3C101C949FB2012BA14E0FE3A355`.

Prefer not to add a repository? Download `redstonepanel_1.13.1_all.deb` below and run `sudo apt install ./redstonepanel_1.13.1_all.deb`. You then install each new version the same way.

The [user guide](https://github.com/qrussell/redstonepanel/blob/main/docs/guide/README.md) walks through every feature, with screenshots.

## Upgrading

If you use the qrussell-repo repository:

```bash
sudo apt update && sudo apt upgrade
```

New versions reach the repository within a few hours of their release. Otherwise, install the new .deb as above.

Running servers keep running through the upgrade.
