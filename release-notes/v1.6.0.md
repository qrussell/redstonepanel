Bring back a server you uninstalled, without writing a systemd unit by hand.

## Added

- **Restore removed servers.** **Uninstall (Keep World)** removes a server's systemd service but leaves its files in `/opt`. Those servers now appear under **➕ New Server → Removed servers** (the sidebar shows "♻️ N removed servers" when there are any). **Restore** gives the server a new service under the same name, then enables and starts it:
  - it keeps its old port, unless another server took that port in the meantime; then it moves to the next free one and tells you
  - the server binary is downloaded only if it's missing. Servers removed with 1.5.0 or earlier had their binary deleted, so restoring one of those downloads the latest release; for a Java server that upgrades the world, so export it first if you might want to go back
  - this also finds servers whose service was deleted some other way
- **From the command line:** `sudo redstonepanel removed` lists removed servers and `sudo redstonepanel restore NAME` restores one, so it works even when the web panel doesn't.
- **Delete a removed server's files** with 🗑 next to it (admins only, can't be undone).

## Changed

- **Uninstall (Keep World) keeps the server binary** (`server.jar` / `bedrock_server`) as well as the worlds, so a restored server runs the same game version it did before. It also remembers the Java heap size, which a restore reuses.

## Fixed

- Uninstalling refuses names that aren't one of the panel's own servers.
- Two deploys or imports started at the same moment could pick the same server name and folder.

## Installing

RedstonePanel runs on **Ubuntu 24.04 and 25.04**. The easiest way to install it, and to get every later version with `apt upgrade`, is the signed **qrussell-repo** apt repository:

```bash
sudo apt install -y curl ca-certificates
curl -fsSL https://qrussell.github.io/qrussell-repo/deb/qrussell-repo.gpg | sudo tee /usr/share/keyrings/qrussell-repo.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/qrussell-repo.gpg] https://qrussell.github.io/qrussell-repo/deb ./" | sudo tee /etc/apt/sources.list.d/qrussell.list
sudo apt update
sudo apt install redstonepanel
```

Then open **http://&lt;server&gt;:8080/** and sign in with a Linux account in the `sudo` group.

To check the repository key before trusting it, `gpg --show-keys /usr/share/keyrings/qrussell-repo.gpg` should show the fingerprint `9994A9EB39EB3C101C949FB2012BA14E0FE3A355`.

Prefer not to add a repository? Download `redstonepanel_1.6.0_all.deb` below and run `sudo apt install ./redstonepanel_1.6.0_all.deb`. You then install each new version the same way.

## Upgrading

If you use the qrussell-repo repository:

```bash
sudo apt update && sudo apt upgrade
```

New versions reach the repository within a few hours of their release. Otherwise, install the new .deb as above. Nothing changes for running servers.
