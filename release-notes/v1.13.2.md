Bedrock servers on any port can show up under **Friends → LAN Games**: RedstonePanel now installs and runs Phantom LAN proxies for them.

## Added

- **Add-ons → Server tools → Phantom** on Bedrock servers (admins). **Install** downloads [Phantom](https://github.com/jhead/phantom) 0.5.4 from GitHub, checks it against a SHA-256 built into the panel, and runs it as `phantom-<server>.service` under the `minecraft` user, starting at boot. It opens UDP 19132 and the Phantom's own port (19300 and up) in ufw. Consoles and phones on your network then list the server under LAN Games, whatever its port.
- The card shows whether Phantom is running, where it forwards, its ports and its recent log, with **Stop** / **Start**, **Restart** and **Uninstall**. **Repair** points it at the server again after you change the server's port.
- Several servers can each have a Phantom. Install is refused, with the reason, while a Bedrock server on this machine uses port 19132, which Phantom needs too.
- Phantom services you set up yourself that point at the server or use its port are listed with what's wrong with them, Start / Stop and **Remove unit** (the unit file only).
- Removing a server removes its Phantom and closes the ports no other Phantom uses.

Panels on 1.13.1 can update with **Update now** on the dashboard; older ones upgrade with apt as below.

## Installing

RedstonePanel runs on **Ubuntu 24.04 and 25.04**. The easiest way to install it, and to get every later version with `apt upgrade`, is the signed **qrussell-repo** apt repository:

```bash
sudo apt install -y curl ca-certificates
curl -fsSL https://qrussell.github.io/qrussell-repo/deb/qrussell-repo.gpg | sudo tee /usr/share/keyrings/qrussell-repo.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/qrussell-repo.gpg] https://qrussell.github.io/qrussell-repo/deb ./" | sudo tee /etc/apt/sources.list.d/qrussell.list
sudo apt update
sudo apt install redstonepanel
```

Then open **http://&lt;server&gt;:8080/** and sign in with a Linux account in the `sudo` group.

To check the repository key before trusting it, `gpg --show-keys /usr/share/keyrings/qrussell-repo.gpg` should show the fingerprint `9994A9EB39EB3C101C949FB2012BA14E0FE3A355`.

Prefer not to add a repository? Download `redstonepanel_1.13.2_all.deb` below and run `sudo apt install ./redstonepanel_1.13.2_all.deb`. You then install each new version the same way.

The [user guide](https://github.com/qrussell/redstonepanel/blob/main/docs/guide/README.md) walks through every feature, with screenshots.

## Upgrading

If you use the qrussell-repo repository:

```bash
sudo apt update && sudo apt upgrade
```

New versions reach the repository within a few hours of their release. Otherwise, install the new .deb as above.

Running servers keep running through the upgrade.
