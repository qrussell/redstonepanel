Each Bedrock server gets its own gameplay port again, so several Bedrock servers can run on one machine.

## Fixed

- **A second Bedrock server clashed with the first.** Since 1.16.4, new Bedrock servers keep the `server.properties` from the Bedrock download, and that file sets `server-udp-ports=19132`: the UDP port current Bedrock servers (NetherNet) use for gameplay. So every new Bedrock server used UDP 19132, and a second one on the same machine fought the first for it. Each new Bedrock server now gets `server-udp-ports` on the same number as its own port (19132, 19134, …), which is also the easiest to forward on a router.
- Moving, importing or restoring a Bedrock server whose port changes moves a matching `server-udp-ports` along with it, applying a template keeps the server's own, and ports in `server-udp-ports` count as taken when the panel picks ports for a new server.

## Upgrading an existing panel

Nothing to do for new servers. If you created **more than one Bedrock server with 1.16.4**, open each one after the first, go to **Configuration**, set `server-udp-ports` to the same number as its `server-port` (shown on **Overview**), **Save Changes** and **Restart** it. The panel then opens the new port in `ufw` if it's installed. If you forward ports on your router or open them in another firewall (for example on Windows with WSL), allow the new UDP port there too.

## Installing

RedstonePanel runs on **Ubuntu 24.04 and 25.04**. The easiest way to install it, and to get every later version with `apt upgrade`, is the signed **qrussell-repo** apt repository:

```bash
sudo apt install -y curl ca-certificates
curl -fsSL https://qrussell.github.io/qrussell-repo/deb/qrussell-repo.gpg | sudo tee /usr/share/keyrings/qrussell-repo.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/qrussell-repo.gpg] https://qrussell.github.io/qrussell-repo/deb ./" | sudo tee /etc/apt/sources.list.d/qrussell.list
sudo apt update
sudo apt install redstonepanel
```

Or in one line: `curl -fsSL https://raw.githubusercontent.com/qrussell/redstonepanel/main/install.sh | sudo sh`

Then open **http://&lt;server&gt;:8080/** and sign in with a Linux account in the `sudo` group.

To check the repository key before trusting it, `gpg --show-keys /usr/share/keyrings/qrussell-repo.gpg` should show the fingerprint `9994A9EB39EB3C101C949FB2012BA14E0FE3A355`.

Prefer not to add a repository? Download `redstonepanel_1.16.5_all.deb` below and run `sudo apt install ./redstonepanel_1.16.5_all.deb`. You then install each new version the same way.

The [user manual](https://github.com/qrussell/redstonepanel/blob/main/docs/guide/README.md) walks through every feature, with screenshots.

## Upgrading

If you use the qrussell-repo repository:

```bash
sudo apt update && sudo apt upgrade
```

New versions reach the repository within a few hours of their release. Otherwise, install the new .deb as above.

Running servers keep running through the upgrade.
