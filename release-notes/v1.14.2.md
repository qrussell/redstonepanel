See who joins your servers, who the whitelist keeps out, and edit the whitelist from the panel.

## Added

- **Player access log.** For every server, the panel keeps who joined, who left and who was turned away, and why: not on the whitelist, banned, wrong game version or server full. It reads the server's own console and log files every 30 seconds. The first scan reads older logs as well, so you see players from before the upgrade, as far back as the logs go. Only player names and IDs (UUID or XUID) are stored, never addresses, and events are kept for 90 days.
- **Configuration → Whitelist & Access.**
  - The **whitelist** (Java) or **allowlist** (Bedrock), with each player's last join, **Allow** and **Remove**. On a running server the change goes through its console and applies at once; otherwise the panel edits the file for the next start.
  - **Turned away in the last 7 days**, with an **Allow** button for each player.
  - The **access log**, filtered by player, event (joined, left, turned away) and period (24 hours to 90 days).
- **Needs attention** on the dashboard lists players turned away in the last 24 hours who still aren't allowed.
- **Notifications:** two new webhook events, **Player joined** and **Player turned away**. Both are off by default.

Bedrock servers don't log refused joins, so on Bedrock the log shows joins and leaves only.

## Installing

RedstonePanel runs on **Ubuntu 24.04 and 25.04**. The easiest way to install it, and to get every later version with `apt upgrade`, is the signed **qrussell-repo** apt repository:

```bash
sudo apt install -y curl ca-certificates
curl -fsSL https://qrussell.github.io/qrussell-repo/deb/qrussell-repo.gpg | sudo tee /usr/share/keyrings/qrussell-repo.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/qrussell-repo.gpg] https://qrussell.github.io/qrussell-repo/deb ./" | sudo tee /etc/apt/sources.list.d/qrussell.list
sudo apt update
sudo apt install redstonepanel
```

Then open **http://&lt;server&gt;:8080/** and sign in with a Linux account in the `sudo` group.

To check the repository key before trusting it, `gpg --show-keys /usr/share/keyrings/qrussell-repo.gpg` should show the fingerprint `9994A9EB39EB3C101C949FB2012BA14E0FE3A355`.

Prefer not to add a repository? Download `redstonepanel_1.14.2_all.deb` below and run `sudo apt install ./redstonepanel_1.14.2_all.deb`. You then install each new version the same way.

The [user guide](https://github.com/qrussell/redstonepanel/blob/main/docs/guide/README.md) walks through every feature, with screenshots.

## Upgrading

If you use the qrussell-repo repository:

```bash
sudo apt update && sudo apt upgrade
```

New versions reach the repository within a few hours of their release. Otherwise, install the new .deb as above.

Running servers keep running through the upgrade.
