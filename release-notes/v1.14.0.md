Find mods and Find plugins are now a catalog: bundles, a hand-picked starter set, categories and sorting, and a details view that says exactly what Install will do.

## Added

- **Bundles.** A few mods or plugins that belong together, installed with one click: only what's missing, with what each one needs, after a world backup (on by default).
  - Fabric: **Performance pack** (Lithium, FerriteCore, Krypton, C2ME, ScalableLux), **Server essentials** (spark, Chunky, LuckPerms, Ledger), **Bedrock players** (Geyser, Floodgate).
  - Paper: **Server essentials** (Chunky, LuckPerms, EssentialsX, CoreProtect), **Build protection** (WorldEdit, WorldGuard, CoreProtect), **Bedrock players** (Geyser).
- **A starter set** of popular server mods and plugins, grouped as Performance, Admin tools, For players and Libraries, checked against the server's loader and Minecraft version. One not updated for your version yet is marked rather than offered.
- **Categories and sorting** when you search, on Modrinth and Hangar: most downloaded, most followed, recently updated or newest.
- **Badges** on every card: Installed, Update available, or Not for this version.
- **Details** when you click a mod or plugin: description, downloads, followers, licence, links, and the version, file and dependencies Install would add, before anything is downloaded.

## Changed

- Backups taken before mod changes (updates and bundles) are now labelled **Before mod changes**.
- Catalog project details are cached for an hour, so the catalog opens quickly.

## Installing

RedstonePanel runs on **Ubuntu 24.04 and 25.04**. The easiest way to install it, and to get every later version with `apt upgrade`, is the signed **qrussell-repo** apt repository:

```bash
sudo apt install -y curl ca-certificates
curl -fsSL https://qrussell.github.io/qrussell-repo/deb/qrussell-repo.gpg | sudo tee /usr/share/keyrings/qrussell-repo.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/qrussell-repo.gpg] https://qrussell.github.io/qrussell-repo/deb ./" | sudo tee /etc/apt/sources.list.d/qrussell.list
sudo apt update
sudo apt install redstonepanel
```

Then open **http://&lt;server&gt;:8080/** and sign in with a Linux account in the `sudo` group.

To check the repository key before trusting it, `gpg --show-keys /usr/share/keyrings/qrussell-repo.gpg` should show the fingerprint `9994A9EB39EB3C101C949FB2012BA14E0FE3A355`.

Prefer not to add a repository? Download `redstonepanel_1.14.0_all.deb` below and run `sudo apt install ./redstonepanel_1.14.0_all.deb`. You then install each new version the same way.

The [user guide](https://github.com/qrussell/redstonepanel/blob/main/docs/guide/README.md) walks through every feature, with screenshots.

## Upgrading

If you use the qrussell-repo repository:

```bash
sudo apt update && sudo apt upgrade
```

New versions reach the repository within a few hours of their release. Otherwise, install the new .deb as above.

Running servers keep running through the upgrade.
