Edit a server's files from the browser: plugin configs, ops.json, mods and more.

## Added

- **File manager.** Each server has a new **Files** tab, for admins. It shows the server's folder in `/opt/minecraft-…`:
  - Open folders, and **Download**, **Rename** or **Delete** files and folders.
  - **Upload** files into the folder you're in, up to 512 MB each, for example a plugin `.jar` into `plugins` on a Paper server or a mod into `mods` on Fabric. Replacing an existing file asks first.
  - Text files up to 1 MB (`.yml`, `.json`, `.properties`, `.toml`, `.txt`, logs…) open in an editor. **Save** or Ctrl+S writes the file. If the server changed it after you opened it, saving stops and asks you to reload, so neither change is lost silently.
  - **New folder** and **New file**.
  - Every change goes in the activity log with the admin who made it.
  - Restart the server after changing settings; most servers read their files at startup.

## Security

The panel runs as root and a game server runs plugins and mods from strangers, so the file manager is careful about what a server folder might contain:

- Nothing outside the server's folder can be reached. Paths are opened one folder at a time without following symlinks, so a symlink in the folder (even one swapped in while a request runs) can't lead to `/etc` or anywhere else. Symlinks are listed, with where they point, but never opened. Files with other hard links aren't opened either.
- New files and folders belong to the `minecraft` user, like the rest of the server, and replaced files keep their permissions.
- It's for admins only. Panel users and visitors on a trusted local network don't see the tab, and the panel refuses their requests.

## Installing

RedstonePanel runs on **Ubuntu 24.04 and 25.04**. The easiest way to install it, and to get every later version with `apt upgrade`, is the signed **qrussell-repo** apt repository:

```bash
sudo apt install -y curl ca-certificates
curl -fsSL https://qrussell.github.io/qrussell-repo/deb/qrussell-repo.gpg | sudo tee /usr/share/keyrings/qrussell-repo.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/qrussell-repo.gpg] https://qrussell.github.io/qrussell-repo/deb ./" | sudo tee /etc/apt/sources.list.d/qrussell.list
sudo apt update
sudo apt install redstonepanel
```

Then open **http://&lt;server&gt;:8080/** and sign in with a Linux account in the `sudo` group.

To check the repository key before trusting it, `gpg --show-keys /usr/share/keyrings/qrussell-repo.gpg` should show the fingerprint `9994A9EB39EB3C101C949FB2012BA14E0FE3A355`.

Prefer not to add a repository? Download `redstonepanel_1.10.0_all.deb` below and run `sudo apt install ./redstonepanel_1.10.0_all.deb`. You then install each new version the same way.

The [user guide](https://github.com/qrussell/redstonepanel/blob/main/docs/guide/README.md) walks through every feature, with screenshots.

## Upgrading

If you use the qrussell-repo repository:

```bash
sudo apt update && sudo apt upgrade
```

New versions reach the repository within a few hours of their release. Otherwise, install the new .deb as above.

Running servers keep running through the upgrade.
