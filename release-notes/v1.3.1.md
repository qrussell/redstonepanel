Fixes Java Edition live chat (RCON) saying it is not connected.

## Fixed

- **Live chat works with any RCON password.** Minecraft Java saves `server.properties` in Java's escaped format: on every start it rewrites a password like `Ab1:c=d!` as `Ab1\:c\=d\!`. The panel read the file literally and sent those backslashes as part of the password, so the server rejected it. Passwords using only letters and digits were unaffected, which is why simple passwords worked. The panel now reads and writes Java servers' `server.properties` exactly as Minecraft does, so symbols (`: = # ! \`) and spaces work.
- **RCON switched off without the panel noticing.** Minecraft and the panel could read the same file differently (for example `enable-rcon=true ` with a trailing space, or a line ending in `\`), leaving RCON off while the panel showed it as on. The panel now sees what Minecraft sees, and when RCON is off it turns it back on and restarts the server, as it already did when RCON wasn't set up.

## Changed

- **Clearer chat errors** instead of "Failed to connect to RCON":
  - *The server rejected the RCON password*: `rcon.password` was changed while the server was running. Restart the server so it uses the new password.
  - *RCON isn't answering*: the server is still starting, or its RCON settings haven't been applied yet. Restart it.
- **Saving properties only rewrites the settings you changed**; other lines keep their original text. Bedrock servers keep their plain format.

## Upgrading

```bash
sudo apt install ./redstonepanel_1.3.1_all.deb
```

Or `sudo apt update && sudo apt upgrade` if you use the qrussell-repo apt repository.

If you changed RCON settings in the panel since a Java server last started, restart that server once so it picks them up.

## Under the hood

- Unit tests for the `server.properties` handling, checked against Java's own parser, now run in the release build.
- Tested end to end: the panel deploys a real Minecraft 26.3 Java server and chats over RCON with generated, symbol and repaired settings on Ubuntu 24.04 and 25.04.
